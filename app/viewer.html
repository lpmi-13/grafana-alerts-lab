Your destinations

Grafana's Lab alerts contact point always notifies this inbox. Add your own destinations and Grafana notifies them too. They last for this playground session only.

Prefer to set up the alert yourself? Sign in to the Grafana tab as admin / lab-demo. Use Alerts & IRM → Alerting → Notification configuration → Contact points to create a Webhook contact point, then Alert rules → New alert rule to create a rule and select that contact point.

Discord and Slack webhook URLs use Grafana's Discord and Slack integrations. ntfy.sh topics get ntfy's Grafana template, so subscribe to the topic in the ntfy phone app to get a push notification. Any other URL receives Grafana's webhook JSON. Anyone who can open this session's Grafana can read a plain webhook URL; Discord and Slack URLs are masked.
